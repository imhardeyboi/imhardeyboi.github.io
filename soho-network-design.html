Enterprise Network Segmentation & Security Architecture

Design and simulation of a secure multi-department enterprise network using Cisco technologies

📌 Project Overview

Designed and simulated a segmented office network connecting Admin, Sales, and HR departments while enforcing security restrictions to prevent unauthorized lateral movement.

🎯 Objectives

  • Design scalable enterprise topology
  • Implement subnetting and routing
  • Apply security restrictions using ACLs
  • Validate connectivity and segmentation

🏗 Network Architecture

DepartmentSubnetGateway
Admin192.168.10.0/24192.168.10.1
Sales192.168.20.0/24192.168.20.1
HR192.168.30.0/24192.168.30.1

🔐 Security Implementation

Implemented an Access Control List blocking HR from accessing Admin resources — a real-world lateral movement prevention control used in enterprise environments. 

access-list 101 deny ip 192.168.30.0 0.0.0.255 192.168.10.0 0.0.0.255
access-list 101 permit ip any any

🧪 Testing Results

  • Admin ↔ Sales: Allowed
  • Sales ↔ HR: Allowed
  • HR → Admin: Blocked
  • Segmentation working as designed
