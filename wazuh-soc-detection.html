Enterprise Threat Detection & Incident Response

Wazuh SIEM | SOC Simulation

Project Overview

This project simulates a real-world cyber attack against a financial institution infrastructure. A Wazuh SIEM platform was deployed to detect brute force attacks and SQL injection attempts in real time.

Lab Architecture

  • Kali Linux – Attacker Machine
  • Ubuntu Server – Transaction Server
  • Apache Web Server
  • Wazuh SIEM
  • Slack Alert Integration

Brute Force Detection

Hydra was used to simulate SSH brute force attacks. Wazuh detected authentication failures and triggered real-time Slack alerts.

SQL Injection Detection

SQL injection payloads were executed against Apache web services. Wazuh successfully detected malicious queries through Apache log monitoring.

Security Outcomes

  • Real-time threat monitoring implemented
  • Attack detection automation achieved
  • Incident response workflow validated
  • Enterprise SOC simulation completed
